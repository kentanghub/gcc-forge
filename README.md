A standalone GitHub-compatible git forge: one statically-linked Go binary serving git smart HTTP v2, REST v3 API, GraphQL v4, and MCP — from its own in-memory store. Zero dependencies, single process.

## Run it

```sh
npm start
```

Built with Go 1.23 — statically linked Linux amd64 binary, vendored as source.
